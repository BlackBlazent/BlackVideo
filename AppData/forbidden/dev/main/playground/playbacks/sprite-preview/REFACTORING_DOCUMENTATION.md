# Sprite Thumbnail Refactoring Documentation

## Overview
The sprite thumbnail preview functionality has been separated from the main timeline controls into dedicated, reusable modules. This improves code maintainability, testability, and reusability.

---

## File Structure

```
├── playback.timeline.controls.ts       # Main timeline controller (refactored)
├── spriteThumbnailManager.ts          # Sprite logic and state management
├── spriteThumbnail.tsx                # React UI component for thumbnail display
└── USAGE_EXAMPLE.tsx                  # Integration example
```

---

## Architecture

### 1. **playback.timeline.controls.ts**
**Purpose:** Main timeline controller focused on seek bar, time display, and playback control.

**Key Changes:**
- Removed all sprite-related DOM manipulation
- Removed `thumbnailContainer` and `thumbnailImage` properties
- Removed `createThumbnailContainer()`, `showThumbnailAtTime()`, and `hideThumbnail()` methods
- Added `spriteThumbnailManager` instance
- Delegates all sprite operations to `SpriteThumbnailManager`

**Responsibilities:**
- Timeline scrubber interaction
- Time display updates
- Seek bar progress tracking
- Video playback control
- **Delegates sprite preview to SpriteThumbnailManager**

---

### 2. **spriteThumbnailManager.ts**
**Purpose:** Pure TypeScript class managing sprite configuration and state.

**Key Features:**
- State management for thumbnail visibility and position
- Sprite configuration (URL, dimensions, grid layout)
- Callback system for state changes
- Helper methods for calculations (thumbnail index, sprite offsets)

**Public API:**
```typescript
// Initialize sprite from video element
initializeSpriteConfig(videoElement: HTMLVideoElement): void

// Update rows based on video duration
updateSpriteRows(duration: number): void

// Show/hide thumbnail
showThumbnailAtTime(time: number, mouseX?: number, mouseY?: number): void
hideThumbnail(): void

// Configuration
setSpriteConfig(config: Partial<SpriteConfig>): void
updateSpriteUrl(url: string): void

// State access
getSpriteConfig(): SpriteConfig
getThumbnailState(): ThumbnailState

// Register for state updates
onStateChange(callback: (state, config) => void): void

// Utilities
calculateThumbnailIndex(time: number): { row, col, index }
calculateSpriteOffset(time: number): { offsetX, offsetY }
reset(): void
```

---

### 3. **spriteThumbnail.tsx**
**Purpose:** React component for rendering the sprite thumbnail preview.

**Props:**
```typescript
interface SpriteThumbnailProps {
  spriteConfig: SpriteConfig;    // Sprite sheet configuration
  currentTime: number;            // Time to display
  mouseX?: number;                // Mouse X position
  mouseY?: number;                // Mouse Y position
  visible: boolean;               // Show/hide thumbnail
}
```

**Features:**
- Automatic sprite offset calculation based on time
- Dynamic positioning near mouse cursor
- Responsive to config and state changes
- Clean, declarative React component

## Integration Guide

### Step 1: Import Required Modules

```typescript
import { primaryPlaybackTimelineController } from './playback.timeline.controls';
import { SpriteThumbnail } from './spriteThumbnail';
import type { SpriteConfig } from './spriteThumbnailManager';
```

### Step 2: Set Up State in Your Component

```typescript
const [spriteConfig, setSpriteConfig] = useState<SpriteConfig>({
  url: '',
  width: 160,
  height: 90,
  columns: 10,
  rows: 0,
  interval: 1
});

const [thumbnailState, setThumbnailState] = useState({
  visible: false,
  currentTime: 0,
  mouseX: undefined,
  mouseY: undefined
});
```

### Step 3: Subscribe to State Changes

```typescript
useEffect(() => {
  const spriteMgr = primaryPlaybackTimelineController.getSpriteThumbnailManager();
  
  spriteMgr.onStateChange((state, config) => {
    setThumbnailState(state);
    setSpriteConfig(config);
  });
}, []);
```

### Step 4: Render the Component

```typescript
<SpriteThumbnail
  spriteConfig={spriteConfig}
  currentTime={thumbnailState.currentTime}
  mouseX={thumbnailState.mouseX}
  mouseY={thumbnailState.mouseY}
  visible={thumbnailState.visible}
/>
```

## How It Works

### Sprite Sheet Generation
Video sprite thumbnails are generated by:
1. Capturing video frames at regular intervals (default: 1 second)
2. Stitching frames into a single image grid (sprite sheet)
3. Naming convention: `video-name-sprite.jpg`

### Grid Layout
```
Default Configuration:
- Grid: 10 columns × N rows (calculated from video duration)
- Thumbnail size: 160px × 90px
- Interval: 1 second per thumbnail
```

Example for 65-second video:
```
Thumbnails needed: 65
Grid: 10 columns × 7 rows (last row has 5 thumbnails)
```

### Thumbnail Display Process

1. **Mouse Hover on Seek Bar:**
   - Timeline controller calculates hover time
   - Calls `spriteThumbnailManager.showThumbnailAtTime(time, x, y)`

2. **Manager Calculates Position:**
   - Determines thumbnail index: `floor(time / interval)`
   - Calculates row and column in grid
   - Updates state and notifies React component

3. **React Component Renders:**
   - Positions thumbnail near cursor
   - Sets sprite image offset to show correct frame
   - Displays with border and shadow

4. **Mouse Leave:**
   - Timeline controller calls `spriteThumbnailManager.hideThumbnail()`
   - Component hides the preview

## Benefits of This Refactoring

### ✅ Separation of Concerns
- Timeline logic separate from thumbnail rendering
- Business logic (manager) separate from UI (component)

### ✅ Reusability
- `SpriteThumbnailManager` can be used in other contexts
- `SpriteThumbnail` component can be used in any React app

### ✅ Testability
- Manager can be unit tested without DOM
- Component can be tested independently

### ✅ Maintainability
- Clear boundaries between modules
- Easy to modify sprite behavior without touching timeline
- Easy to change UI without touching business logic

### ✅ Type Safety
- Full TypeScript support
- Clear interfaces and contracts

## Customization Examples

### Custom Sprite Configuration
```typescript
const spriteMgr = primaryPlaybackTimelineController.getSpriteThumbnailManager();

spriteMgr.setSpriteConfig({
  width: 200,       // Larger thumbnails
  height: 112,
  columns: 8,       // Fewer columns
  interval: 2       // One thumbnail every 2 seconds
});
```

### Custom Sprite URL
```typescript
spriteMgr.updateSpriteUrl('https://cdn.example.com/video-sprite.jpg');
```

### Custom Thumbnail Styling
Modify `spriteThumbnail.tsx`:
```typescript
style={{
  border: '3px solid #00ff00',  // Green border
  borderRadius: '8px',           // More rounded
  boxShadow: '0 8px 16px rgba(0,0,0,0.5)'  // Stronger shadow
}}
```

## Troubleshooting

### Thumbnail not appearing?
- Check that sprite URL is correct (logged in console)
- Verify sprite image exists and is accessible
- Check that React component is rendered
- Verify state callback is registered

### Wrong thumbnail showing?
- Verify sprite interval matches actual sprite generation
- Check columns/rows configuration
- Ensure sprite sheet follows expected grid layout

### Position issues?
- Check mouse coordinates are passed correctly
- Verify container positioning logic
- Adjust thumbnail offset calculations if needed
