    ├─→ saved.captured.ts (File saving)
    └─→ connector.ts (Video stage access)


┌─────────────────────────────────────────────────────────────────────┐
│                         Data Flow                                    │
└─────────────────────────────────────────────────────────────────────┘

1. Initialization:
   index.ts → connector.ts → Video Theater Stage
                            → float.render.ui.tsx

2. Mode Selection:
   float.render.ui.tsx → recorder.control.ui.tsx → Specific Controller

3. Recording:
   Controller → video.recording.ts → MediaRecorder API
                                   → Canvas API
                                   → getUserMedia API

4. Saving:
   Controller → video.recording.ts → saved.captured.ts → File System
                                                        → Downloads Folder
