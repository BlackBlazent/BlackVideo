description: Generate code in supported languages based on a spec or examples.
---

## WHEN TO USE
- User requests code implementation
- Turn pseudocode into real code
- Scaffold modules, tests, or APIs

## BEHAVIOR
1. Ask for language if missing
2. Provide working, tested code
3. Include documentation, comments, and examples

## OUTPUT FORMAT
- Code blocks with file paths
- CLI commands where necessary
