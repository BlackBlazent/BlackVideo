# Document Analysis Skill

## WHEN TO USE
- When a user uploads or references a document.
- When the user asks for summaries, key points, or metadata extraction.

## INSTRUCTIONS
1. Read provided document content.
2. Identify topic, structure, and main points.
3. Provide a summary and optionally extract structured data (tables, entities).
4. Return output in requested format (JSON/table/markdown).

## EXAMPLES
User: “Summarize the uploaded contract and list clauses with deadlines.”  
Skill: Returns clause list with deadlines and short summaries.

# Code Review Skill

## WHEN TO USE
- When user asks for a code review or analysis of a code snippet.
- When user wants performance, security, or style improvements.

## INSTRUCTIONS
1. Read the given code.
2. Identify issues (bugs, style, security, etc.).
3. Suggest improvements.
4. Provide examples of fixes and test cases.
