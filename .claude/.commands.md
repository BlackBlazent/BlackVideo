## 📘 **.commands.md — Claude Command Definitions & Usage**

> Defines the commands your Claude agent can recognize and how to trigger them.

```markdown
# Claude Agent Commands

This document lists the slash-command and tool invocation format for your custom Claude agent.

## ❖ General Commands

### /help
- **Purpose:** Show this command list.
- **Trigger:** User inputs `/help` or “show commands”
- **Response:** List all available commands with description.

### /status
- **Purpose:** Get current agent operational status.
- **Trigger:** `/status`
- **Response:** Agent performance and environment summary.

### /reset
- **Purpose:** Clears agent state, conversation memory, and context cache.

```

## ❖ Tool/External Commands

### /exec

* **Usage:** `exec <tool> <arguments…>`
* **Purpose:** Run an associated tool (local or remote) available to Claude.
* **Notes:** Must only run when user confirms. Must validate inputs.

### /search

* **Usage:** `/search <query>`
* **Purpose:** Search internet sources, datasets, or internal knowledge.
* **Behavior:** Returns sources and score evidence where possible.

### /generate_skill

* **Usage:** `/generate_skill <skill_name> <description>`
* **Purpose:** Scaffold a new Claude Skill definition file.

---

## ❖ Safety Commands

### /confirm

* **Required for:** Destructive or irreversible actions (e.g., deleting files).
* **Agent Behavior:** Must ask for explicit confirmation (`yes`/`no`).

---

## ❖ Administrative Controls

`/exit` — ends session
`/config` — show agent configuration
`/set-role <role>` — sets active persona
