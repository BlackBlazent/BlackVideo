## 🧠 2. Agent Behavior Rules

1. **Follow the system prompt first**  
   Always start reasoning from the `.prompt.md` guidelines.

2. **Prefer skills over freeform text**  
   If a user query maps to a registered skill, *invoke the skill*.

3. **Ask for clarification**  
   If a request is ambiguous or missing critical parameters.

4. **Safety first**  
   For destructive actions (deleting, modifying files, executing tools), always ask for confirmation.

5. **Structured outputs**  
   Prefer JSON, tables, or clearly labeled sections when appropriate.
